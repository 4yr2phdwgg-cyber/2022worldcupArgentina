
# Football Data Analysis & Learning

A personal football data analysis learning repository focused on building practical skills in Python, Pandas, data cleaning, exploratory analysis, and visualization.

## About This Repository

This repository documents my progression from Python/Pandas fundamentals to practical football data analysis.

The main goal is to combine my interest in football with data analysis skills and gradually build a portfolio for future football data analyst opportunities.

## Skills

* Python
* Pandas
* NumPy
* Matplotlib
* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Basic Statistical Analysis

## Projects & Exercises

### 1. Football Match Data Analysis

Analyzed football match datasets to explore team and player performance.

Key analysis areas include:

* Match-level statistics
* Team performance
* Passing and attacking statistics
* Player performance
* Relationship between passing and attacking outcomes
* Data aggregation and visualization

### 2. Passing & Attacking Analysis

Explored the relationship between passing activity and attacking performance.

Main techniques:

* Pandas data manipulation
* GroupBy aggregation
* Feature selection
* Data visualization
* Comparative analysis

## What I Learned

Through these projects, I practiced:

1. Loading and cleaning real-world datasets
2. Handling missing values and inconsistent data
3. Using Pandas for multi-step analysis
4. Aggregating data by teams, players and matches
5. Creating meaningful visualizations
6. Translating football questions into data analysis questions
